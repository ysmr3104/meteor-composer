# ADR — このリポジトリの決定記録

**「なぜそう決めたか」を置く場所です。** 「何を満たすべきか」は `../requirements.md`、同じ失敗を繰り返さないための教訓は `pixinsight-handbook/docs/lessons.md` にあります。使い分けは handbook の `CLAUDE.md`（文書の置き場）を見てください。

リポジトリをまたぐ決定（リリース手順、公開サイトの方針など）は**ここではなく** `pixinsight-handbook/docs/adr/` に置きます。ここに置くのは MeteorComposer 固有の決定だけです。

## 書き方

Michael Nygard の ADR に、MADR の「検討した案」を足した形です。1 決定 1 ファイル、`NNNN-短い題.md`。**番号は振り直さない**（他から参照されるため）。

```markdown
# NNNN. 決定の要約（動詞で終える）

日付: YYYY-MM-DD
ステータス: 提案 / 採用 / 却下 / 廃止（NNNN に置き換え）

## 背景

何が起きて、何を決める必要が生じたか。**測った数字があるならここに書く。**

## 決定

何を決めたか。断定形で書く。

## 検討したが却下した案

案と、**却下した理由**。これが無い ADR は後から読んでも役に立ちません。

## 結果

これによって何が良くなり、**何を代償として払ったか**。
```
