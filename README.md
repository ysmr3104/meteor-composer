# MeteorComposer

一眼カメラで撮影した流星群の連番画像から流星を自動検出し、人手によるスクリーニングを経て、流星群コンポジット画像を生成する PixInsight スクリプトです。

Python や外部プロセスを必要とせず、PJSR のみで動作します。

---

## できること

| Stage | 内容 |
|---|---|
| 1. 検出 | 全フレームを走査し、流星候補のリストを生成する |
| 2. スクリーニング | 候補リストとプレビューを表示し、人の目で採否を判断する |
| 3. マスク生成 | 採用した候補の流星痕マスクを、光の分布から生成する |
| 4. コンポジット | master light に流星だけを合成した画像を生成する |

検出は候補を提示するところまでで、**何も自動で捨てません**。採否は必ず人が決めます。分類器は候補を並べ替えて絞り込みを助けるだけで、既定では何も隠しません。

### スクリーニング

- 候補を原寸（1:1）でプレビュー表示し、キーボードで判定できます
- 判定は**判定するたびに自動保存**されるので、保存を忘れて失うことがありません
- 衛星・飛行機（複数フレームにまたがって移動するもの）を隠せます
- スコアで絞り込めます。既定は何も隠さない `Loose` です

### 検出対象エリアの除外

地上景などを検出対象から外せます。辺ごとの食い込み量と傾きで指定するか、黒く塗った画像を読み込みます。除外範囲はプレビューに重ねて表示され、**除外面積の実測値**が常に出ます。

なお **registered フレームの外側（位置合わせではみ出した領域）は自動的に除外される**ので、そこを手で塞ぐ必要はありません。

## 対象とする撮影データ

ダイアログの **System** で座標系を選びます。

| | 空基準（Sky-referenced） | 地上基準（Ground-referenced） |
|---|---|---|
| 撮影 | 赤道儀による追尾 | 三脚による固定 |
| 検出が読む | `registered`（WBPP で位置合わせ・デベイヤー済み） | `debayered` |
| 合成の背景 | master light | `debayered` の 1 枚、または数枚の中央値 |
| 位置合わせ | 必要 | **不要** |
| 流星の位置 | 星座に対して正しい | 風景に対して正しい |

**長時間の固定撮影を位置合わせしてはいけません。** 4 時間 13 分・1045 枚のデータでは、StarAlignment が 327 枚を落とし、残った 718 枚も平均 36.5% が空になりました。参照フレームを夜の中央に選び直しても欠損は 66% → 59% にしかならず、これは幾何であって設定では解けません。さらに空を揃えて積分する以上、master light の地上は 63° の円弧に伸びます。

三脚は動いていないので、**フレーム N の流星をその画素位置のまま置けば地上に対して正しい位置に出ます。** 詳細は [docs/requirements.md](docs/requirements.md) 3.4 を参照してください。

## 動作環境

- **PixInsight 1.9.4 以降（V8 エンジン専用）**
- 外部依存なし

## インストール

PixInsight の `Resources > Updates > Manage Repositories` に次の URL を追加し、`Check for Updates` を実行してください。

```
https://ysmrastro.github.io/pixinsight-scripts/
```

インストール後、`Script > Image Analysis > MeteorComposer` または `Script > ysmrastro > MeteorComposer` から起動します。

## 使い方

1. **System** で **Sky-referenced**（追尾）か **Ground-referenced**（固定撮影）を選びます
2. **Frames** にフレームのディレクトリを指定します（空基準なら `registered`、地上基準なら `debayered`）。1 枚目がプレビューに表示されます
3. **Output** に書き出し先を指定します。検出結果・判定・コンポジットがすべてここに書かれます（入力ディレクトリには何も書きません）
4. 必要なら **Mask** で地上景などを除外します
5. **Run detection** を実行します
6. 候補を 1 件ずつ判定します（`M` 流星 / `N` 違う / `U` 保留）
7. **Compose...** で背景を指定し、コンポジットを生成します

**System は検出結果ができた時点でロックされます。** 検出・スクリーニング・合成は 1 つの座標系で閉じる必要があるためで、Reset で解除されます。

## 実測値

2026-08-12 の 654 フレーム（ILCE-7M3、13 秒露出）で測った値です。

| | |
|---|---|
| 検出候補 | 360 |
| 目視で確認した流星の検出 | **9 / 9** |
| 検出時間 | 約 9 分（810 ms / フレーム） |
| コンポジットでマスク外が変化した画素 | 0 |

## 開発

Small テスト（Node.js のみで動作、PixInsight 不要）:

```bash
for f in tests/ut/*.js; do node "$f"; done
```

実データを使う評価と PJSR probe は `tests/eval/` と `tests/pjsr/` にあります。方針は [docs/tests.md](docs/tests.md) を参照してください。
